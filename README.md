# あと何単位？

琉球大学の卒業要件を、成績表から計算するページです。いまは人文社会学部 国際法政学科（2023〜2026年度入学）に対応しています。

https://nocommune.github.io/tani-check/

- 学部・学科・入学年度を選び、教務システムの成績表のPDFを読み込むと、科目区分ごとの修得単位から、卒業まであと何単位かを表示します。
- 便覧の振替（選択科目の要件を超えた単位・共通教育の要件を超えた単位を専門自由科目へ、など）を自動で計算します。
- PDFはブラウザの中だけで読みます。氏名・学籍番号・GPA・科目ごとの評価は読み込まず、どこにも送りません。

大学の公式のツールではありません。最終的な判定は、所属学部の事務窓口で確認してください。
